# 蛊真：大道唯我 MVP

这是一个 Godot 4 单机可玩原型，基于当前目录中的玩法文档和界面预览图搭建。

## 运行

1. 使用 Godot 4.2 或更高版本打开 `project.godot`。
2. 运行主场景 `res://scenes/Main.tscn`。
3. 第一次进入会显示创建角色页；之后会自动读取 `user://guzhen_save.json` 存档。

## 已实现闭环

- 创建角色：姓名、性别、出身、天赋、主修流派。
- 仙窍经营：资源产出、寿元推进、节点压力、告警和日志。
- 仙蛊炼制：资源消耗、成功率、唯一仙蛊校验、反噬。
- 杀招配置：核心蛊与辅助蛊组合，生成威力、稳定度、风险和冷却。
- 宝黄天：出售资源、购买材料、散布情报。
- NPC 交互：交易、结盟、威胁和关系变化。
- 实时战斗：WASD 移动，Space/1 释放杀招，敌人追击，胜负结算。
- JSON 存档：当前使用 `user://guzhen_save.json`，后续可替换为 SQLite。

## 素材策略

现有预览图已复制到 `res://assets/reference/`，作为视觉参考与暗色背景使用。MVP 的按钮、面板、进度条、卡牌和战斗单位均由 Godot 控件/绘制代码生成，不依赖从截图中硬切 UI。

后续需要补充的独立素材见 `res://docs/resource_requirements.md`。
